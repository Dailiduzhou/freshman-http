# 流光 · 彩虹跑马灯

直接用现代浏览器打开 [`index.html`](./index.html)。原生 HTML / CSS / JavaScript，无构建、无依赖、无网络请求。

## 使用

- **设置**：展开 / 收起编辑面板；输入即时生效。字幕始终单行、水平向左无缝循环，换行按空格处理。
- **字体**：选择预设字体、输入一个已安装的字体名称，或加载本地 `.woff2` / `.woff` / `.ttf` / `.otf` 文件（不超过 30 MB）。字体文件仅在浏览器内处理，不上传、不跨次保存。
- **字重**：100–900；实际显示取决于字体提供的字重，建议使用可变字体。
- **高级设置**：字号、字幕速度、彩虹流速、色带倾角、背景色。
- **暂停 / 继续**：同时冻结或恢复字幕位置和彩虹颜色。
- **全屏**：进入全屏时自动收起设置，底部保留操作入口。可按 Esc 退出；不支持全屏 API 的浏览器会给出提示。
- **恢复默认**：重置内容和显示参数、清除本次加载的字体；不改变当前暂停状态。

默认：黑色背景、160 px / 700 字重、字幕速度 100 px/s、彩虹流速 40 px/s、色带倾角 45°。倾斜的是**渐变色带的分界线**（左上到右下），不是文字，也不是文字运动路径。

文本和参数通过 `localStorage` 保存在当前浏览器。上传字体后重新打开会回退到默认黑体，需重新选择字体文件。隐私模式或浏览器限制可能使保存不可用，届时仍可正常编辑和播放。同一文件移动位置后，原设置不一定沿用。

遵循系统“减少动态效果”偏好：首次加载先暂停，可手动点击“继续”。切到后台时停止动画，返回时从原位置继续，避免突然跳动。

## 实现

- 根据文字实际宽度及视口宽度创建足够的文本副本，按一个副本宽度取模循环。
- 一整条轨道共享连续的重复线性渐变，利用 `background-clip: text` 将颜色限制在字形内。
- 文字位移和彩虹相位分别计算；补偿轨道位移，使颜色在展示区域内独立流动。
- 渐变图像的水平、垂直平铺尺寸均对应整数个光谱周期，避免图像平铺接缝；颜色相位按同一周期循环。
- 窗口大小变化、字体加载、文本和字重修改后重新测量；用户文本通过 `textContent` 渲染，不解释为 HTML。

## 检查

已在 Chromium 中检查直接打开文件、短文本铺满、换行与 HTML 字面量、暂停 / 恢复、即时参数修改、刷新保存、本地字体加载与回退、空文本、恢复默认、全屏、手机尺寸布局、损坏存储降级、减少动态效果偏好。通过渐变截图像素检查确认 45° 分界方向及平铺处颜色连续。

其他浏览器可手动检查：打开页面 → 输入很短的文本 → 调快滚动观察循环 → 暂停确认颜色也静止 → 继续 → 加载字体 → 刷新 → 进入 / 退出全屏。
